What is GitHub?
===============

GitHub is a web-based platform used for version control and collaboration on software projects. It allows developers to host their code repositories, track changes to their codebase, and manage collaborative development workflows. Our Public External repository, which is open to all, is at:

https://github.com/department-for-transport-public/D-TRO

Note: in order to actively participate on the GitHub repository (e.g. commenting on issues), you will require a GitHub username, but these are available free of charge.
