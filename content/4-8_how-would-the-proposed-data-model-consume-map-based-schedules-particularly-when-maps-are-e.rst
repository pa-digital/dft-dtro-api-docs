How would the proposed data model consume map-based schedules? Particularly when maps are exported as a raster to reduce file size?
===================================================================================================================================

All submissions to the D-TRO service need to comply with the D-TRO Data Specification. It  possible to simply upload maps in raster format. The provisions of the TRO will need to be encoded in JSON format conforming to the D-TRO Data Specification appropriate geospatial referencing.
