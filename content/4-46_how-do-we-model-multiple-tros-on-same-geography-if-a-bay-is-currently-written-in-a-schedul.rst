How do we model multiple TROs on same geography? If a bay is currently written in a schedule item as Limited waiting 8am to 8pm and then in the same TRO the same bay is also listed as 8pm to 8am taxis only. In your view is that inputted as 2 DTROs or one as they are in the same TRO?
===========================================================================================================================================================================================================================================================================================

D-TRO records are the content from one TRO. If multiple provisions exist in the same geography as a result of multiple TROs there should be multiple D-TRO records.

A D-TRO record (a single TRO) can contain multiple Provisions – so in the quoted example we would expect a single D-TRO record with separate Provisions for Limited Waiting and Taxi only restrictions.
